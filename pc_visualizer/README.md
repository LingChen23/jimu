# PC Motion Visualizer

本目录是独立的本地 Python 可视化工具，支持：

- 浏览并打开/关闭串口；
- 为 1～12 号设备分别保存数据；
- 显示设备发送的坐标轨迹；
- 以三维等轴视图显示 X/Y/Z 轨迹，并可切换 XY、XZ、YZ 投影；
- 显示三轴加速度和三轴角速度；
- 用加速度、角速度和静止检测计算一条 PC 端惯导轨迹；
- 检查包序号并统计丢包。
- 按“静止 → 移动 → 稳定静止”划分完整移动并保存统计结果；
- 支持清零当前设备的轨迹和运动统计。

## 启动

```powershell
cd D:\AIOT\majiang\motion_system\pc_visualizer
python -m pip install -r requirements.txt
python app.py
```

浏览器会自动打开：

```text
http://127.0.0.1:8765
```

当前 ESP32-S3 使用 `COM14`、`921600` 波特率。串口同一时间只能被一个
程序占用，启动前请关闭其他串口监视器。

## 当前数据源

后端直接读取二进制串口流：

```text
COBS(114字节网关帧) + 0x00
```

每个网关帧使用 CRC32 校验，并原样携带一个 nRF Motion V1 100字节包。
后端会解析每包四个 IMU 样本，因此单设备正常速率为每秒25包、100个
加速度样本和100个角速度样本。串口状态接口同时提供字节数、COBS错误、
CRC错误、格式错误和网关序号丢帧统计。

PC 惯导轨迹是轻量级对照算法，包含陀螺仪姿态积分、加速度重力修正、
世界坐标转换和静止零速约束。PC 端使用与 nRF 实时轨迹代码相同的六面
加速度标定矩阵和零偏，并在每次移动开始时将两条轨迹同时平移到
`(0, 0, 0)`。由于 ICM-20689 没有磁力计，yaw 仍只能相对积分；PC 轻量
算法也没有完整复刻设备端15状态误差 EKF，因此两条轨迹应从同一点开始且
总体方向接近，但长距离双积分仍可能逐渐产生差异。

## 完整移动统计

设备坐标标志从静止变为移动时开始新的一次移动；回到静止并持续
`0.8 s` 后结束。小于该结束窗口、随后又恢复移动的静止区间计为停顿。
每次移动保存：

- 动态线性加速度模的均值、最大值和最小值；
- 实际移动样本时间；
- 剧烈晃动次数；
- 翻转次数；
- 三轴累计达到 360° 的完整旋转次数；
- 移动过程中的停顿次数。

剧烈晃动初始阈值为动态加速度 `1.5 g` 或角速度 `300 °/s`，带
`0.45 s` 防抖。翻转使用相对初始朝向超过 `120°` 并持续 `0.2 s`；
回到 `60°` 以内后重新允许计数。这些阈值是首版测试参数，需要根据实际
积木动作数据继续标定。
